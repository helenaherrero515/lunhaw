# Security Policy

## Reporting a vulnerability

Please **don't open a public GitHub issue** for security problems.

Email **lunhaw.hln@gmail.com** with:

- what you found and where (URL, endpoint or file),
- steps to reproduce it,
- what an attacker could do with it.

You'll get a reply within 7 days. Please give us a reasonable time to fix the problem before you disclose it publicly.

## Scope

- The website: <https://lunhaw.pages.dev>
- The API: `lunhaw-api-production.*.workers.dev`
- The code in this repository

Out of scope: third-party services Lunhaw relies on (Supabase, Cloudflare, OpenFreeMap, OpenRouteService, Anthropic). Report issues in those to their vendors.

## Please don't

- access, change or delete other people's data,
- run load tests or denial-of-service attempts,
- send spam through the sign-up or newsletter forms.
